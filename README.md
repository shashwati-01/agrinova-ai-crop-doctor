# AgriNova – AI Crop Doctor

## Overview
AgriNova is an AI-powered agricultural decision support system developed using Python and Machine Learning. The application helps farmers and agricultural users select suitable crops based on soil and environmental conditions.

## Features
- Crop Prediction
- Soil Analysis
- Fertilizer Recommendation
- Data-driven Insights
- User-friendly Interface

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- CSS

## Project Files
- app.py
- crop.csv
- soil.csv
- style.css
