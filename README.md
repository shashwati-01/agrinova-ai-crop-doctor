# AgriNova – AI Crop Doctor

## Overview
AgriNova is an AI-powered agricultural decision support system developed using Python, Machine Learning, and Streamlit. The system predicts suitable crops and provides agricultural insights based on soil parameters.

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn

## Project Structure
- app.py
- crop.csv
- soil.csv
- style.css

## How to Run

### Step 1
Create a folder and place all project files inside it.

### Step 2
Open Command Prompt in that folder.

### Step 3
Install Streamlit:

```bash
pip install streamlit
```

### Step 4
Run the application:

```bash
python -m streamlit run app.py
```

### Step 5
Open the local URL generated by Streamlit in your browser.
